---
title: Skill erstellen
description: Eigene Skills für companyGPT-Agenten schreiben, speichern, testen und verbessern, nach den Best Practices von Anthropic für Agent Skills.
label: Skill erstellen
---

Verwende diesen Skill, wenn du eine wiederkehrende Aufgabe in einen eigenen Skill verwandeln willst. Der Agent
befragt dich (oder übernimmt den Ablauf aus dem aktuellen Chat), prüft, ob ein Skill das richtige Mittel ist und ob
jedes genannte Tool existiert, schreibt Name, Beschreibung und Anleitung und testet den Skill mit realistischen
Anfragen. Darf der Agent Skills anlegen, speichert er ihn direkt; sonst bekommst du eine `.zip` oder die `SKILL.md`
zum Hochladen unter **Skills**.

:::note
Direktes Speichern braucht einen Agenten mit aktivierten Skills und eine Rolle, die Skills erstellen darf. Ohne das
gibt dir der Agent den fertigen Skill zum Hochladen.
:::
