You reach the companyFILES interface in CompanyGPT via **Apps → Files** or via the [All apps](/en/company-gpt/addons/alle-apps/) page. It uses the [shared interface](/en/company-gpt/addons/gemeinsame-oberflaeche/) of all CompanyGPT addons: sign-in runs through your chat session, and layout and design match the chat.

## Sidebar and account menu

The sidebar can be expanded and collapsed. From top to bottom it contains:

| Item | Effect |
|---|---|
| **New chat** | opens a new chat in CompanyGPT |
| **All apps** | leads to the overview of all apps in your environment |
| **[Documents](#documents)** | all generated and uploaded files; also the start page of companyFILES |
| **[Templates](#templates)** | all available templates |
| **[Visualizations](#visualizations)** | all charts, diagrams and maps created in the chat |
| **Settings** | defaults for generated documents – see [Settings](/en/company-gpt/addons/companyfiles/einstellungen/) |

Your account sits at the very bottom. The **account menu** shows your e-mail address and contains:

- **Theme** – **System**, **Dark**, **Light**, **High contrast light** or **High contrast dark**,
- **Language** – Deutsch or English,
- **Log out**.

![companyFILES sidebar with New chat, All apps, Documents, Templates, Visualizations and Settings, plus the open account menu with Theme, Language and Log out](./files-seitenleiste-kontomenue.png)

On a phone, navigation sits in a header with a fold-out menu. If your account is not enabled for companyFILES, the interface shows the **No access** page instead of its content. More on navigation, the account menu and the state pages is under [Shared interface](/en/company-gpt/addons/gemeinsame-oberflaeche/).

Uploading no longer happens through separate menu items but through **page actions** at the top right of the respective page: **Upload Files** on the Documents page and **Template Upload** on the Templates page.

## Documents

This is where all generated and uploaded files live in one place – including the files you attached in the chat.

![Documents page with search, type filter and sorting, listing five files, including a PDF attached in the chat with the CompanyGPT badge and an image with a thumbnail](./files-dokumente.png)

Use the search **Search documents...**, the **All Types** filter (Word, Excel, PowerPoint, PDF, Text, Image, Archive) and **Sort by** (Date, Name, Size, Type) to find files quickly. The table shows **Name**, **Type**, **Size**, **Date** and **Expires**. Small images (up to 1 MB) appear as a thumbnail next to the name; all other files show the icon of their type.

The **CompanyGPT** badge next to the file name means: the file exists as a file in the CompanyGPT chat – either because you uploaded it in the chat or because companyFILES stored a generated document there.

Clicking a row opens the **Preview**. The **three-dot menu** (⋯) lets you download a file, open the preview, edit the expiry date or delete the file. In the view embedded in the chat, the menu shows **Copy link** instead of **Download**.

### Preview

The preview shows the content of PDFs, images and text files directly in the browser; for Word, Excel and PowerPoint files it shows a placeholder with the file type and name. For other file types it offers **Download instead**. If the extension for reading further formats is active in your environment, it shows e-mails, ZIP archives and older Office formats as readable text – see [Reading e-mails, archives and older formats](/en/company-gpt/addons/companyfiles/dokumente-erstellen/#reading-e-mails-archives-and-older-formats).

Clicking an image opens it full screen. There you zoom with the mouse wheel, a pinch gesture or `+`/`−`, pan by dragging or with the arrow keys, fit it to the screen with `0` and close it with `Esc`. **Open in new tab** shows the image in a browser tab of its own.

### Expiry and retention

Generated documents and documents uploaded in companyFILES have a retention period whose length is set by your environment. The **Expires** column shows the remaining time; clicking it, or **Edit Expiry** in the menu, changes the date. When the period ends, companyFILES deletes the document automatically – if it also exists as a file in the CompanyGPT chat, that file is deleted as well.

**Permanent** appears only for files you uploaded directly in the chat. No companyFILES retention period applies to them.

### Uploading files

The **Upload Files** page action opens the **Upload** dialog. Drag one or more files into the upload area or click to browse, then start the upload with **Upload Files** (with several files: **Upload n files**). After the upload the dialog shows the result for each file; **Upload More** continues with the next files.

![The Upload dialog with the upload area and the Upload Files button](./files-dateien-hochladen.png)

Accepted are:

- Office documents (`.docx`, `.xlsx`, `.pptx`, `.potx`),
- PDF,
- images (PNG, JPG, GIF, WebP, BMP, SVG, HEIC),
- ZIP archives,
- text formats such as TXT, Markdown, CSV, JSON, XML, HTML, YAML, CSS, JS and TS.

If the extension for reading further formats is active, e-mails (`.msg`, `.eml`), older Office formats (`.doc`, `.xls`, `.ppt`), Excel binary workbooks (`.xlsb`), RTF, OpenDocument, EPUB and TIFF, among others, are added.

The upload area briefly summarizes these file types. During the upload companyFILES checks whether a file's content matches its extension. Renamed files – a ZIP archive with the extension `.docx`, for example – and files whose content cannot be identified are rejected.

## Templates

Here you can see all available templates for document generation.

![Template list with the columns name, type, scope, tags, size and uploaded, plus the User and Global badges](./files-vorlagen-liste.png)

Use the search **Search templates...** and the filters **All Types**, **All Scopes** and **All Tags** to narrow down the list. The table shows name, type, scope, tags, size and upload date. The **scope** determines visibility:

| Scope | Meaning |
|---|---|
| **User** | usable only by yourself |
| **Global** | usable by every user in the organization |

Clicking a template opens its detail view with description, tags and the detected **Placeholders** – in the notation the template type expects. This lets you check whether a template is prepared correctly.

![Detail view of the Musterbrief template with the User badge, description, tags, the detected placeholders and the Download, Edit and Delete buttons](./files-vorlage-details.png)

At the bottom of the detail view are the actions:

| Action | Available |
|---|---|
| **Download** | for every template |
| **Edit** (display name, description, tags) and **Delete** | for your own templates; for global templates only for administrators |
| **Promote to Global** | for administrators on their own Word, Excel and PowerPoint templates |
| **Demote to Local** | for administrators on global Word, Excel and PowerPoint templates |
| **Use Template** | only in the view embedded in the chat: writes a request to fill the template, including its placeholders, into the chat |

How templates are prepared and used in the chat is described under [Templates](/en/company-gpt/addons/companyfiles/vorlagen/).

### Upload Template

The **Template Upload** page action on the Templates page opens the upload form.

![The Upload Template page with the upload area and the Template Name, Display Name, Description and Tags fields, in the view without administrator rights](./companyfiles-vorlage-hochladen-en.png)

Drag a template file (`.docx`, `.xlsx`, `.potx`, `.pptx`) into the upload area. Fill in the **Template Name** – it is required and may only contain letters, numbers, dashes and underscores – and optionally **Display Name**, **Description** and **Tags** (comma-separated). Administrators also see the **Scope** field: **Global** (available to all users, preselected) or **User** (only visible to themselves). Click **Upload Template** to complete the upload.

## Visualizations

Here you see all charts, diagrams and maps produced by CompanyGPT.

![Visualizations page with the All Items filter and cards for charts, diagrams and a map, each with type and creation date](./companyfiles-visualisierungen-en.png)

The **All Items** filter narrows the view to **Charts**, **Diagrams** or **Maps**. Each card shows the title, an icon, the type and the creation date. Clicking a chart or diagram opens its detail view; maps open in a new browser tab.

How visualizations are produced is described under [Visualizations](/en/company-gpt/addons/companyfiles/visualisierungen/).
