Willkommen in der API-Referenz. Hier finden Sie die Dokumentation für alle verfügbaren APIs.

## APIs

- [companyRAG API](/de/api/company-rag-api/) – API-Schnittstelle für den companyRAG Indexer
  - [companyRAG API Reference](/api/companyrag/) – vollständige Endpunkt-Referenz, generiert aus der OpenAPI-Spezifikation
- [CompanyGPT Agents API](/de/api/agents-api/) - API für CompanyGPT Agents
- [AI Gateway API](/de/api/ai-gateway/) – OpenAI-, Anthropic- und Gemini-kompatibler Zugriff auf die KI-Modelle Ihrer Umgebung mit persönlichem API-Schlüssel (nicht in allen Umgebungen verfügbar)
