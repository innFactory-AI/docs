title: Hochladen

---

Über **Hochladen** fügen Sie einzelne oder mehrere Dateien direkt einer Sammlung hinzu. Das ist der schnellste Weg, um einen Bestand zu testen oder einmalige Dokumente zu ergänzen. Für wiederkehrende Bestände verwenden Sie stattdessen eine [Quelle](/de/company-gpt/addons/companyrag/quellen/).

Ablauf auf der Seite **Dokumente hochladen**:

1. **Sammlung** auswählen, welcher die Dokumente hinzugefügt werden sollen. Zur Auswahl stehen nur Sammlungen, in denen Sie Besitzer oder Administrator sind. Gibt es keine, zeigt die Seite **Keine beschreibbaren Sammlungen**.
2. Dateien in die Ablagefläche ziehen oder über Klick auswählen.
3. Mit **Dokument hochladen** bzw. **… Dokumente hochladen** starten. Die Seite zeigt den Fortschritt je Datei.
4. Jede Datei wird als Auftrag angelegt und indexiert; den Status sehen Sie unter [Aufträge](/de/company-gpt/addons/companyrag/auftraege/).

## Unterstützte Formate

`.pdf`, `.txt`, `.md`, `.docx`, `.pptx`, `.xlsx`, `.rtf`, `.xml`, `.odt`, `.ods`, `.odp`, `.html`, `.htm`, `.csv`, `.tsv`, `.parquet`, `.json`, `.eml`

Das alte Excel-Format `.xls` wird nicht unterstützt. Speichern Sie solche Dateien in Excel als Arbeitsmappe (`.xlsx`).

Dateien über 50 MB markiert die Oberfläche mit einem Hinweis. Die maximale Größe eines Uploads legt Ihre Umgebung fest.

:::note
Manuell hochgeladene Dokumente haben keine Quellverlinkung auf ein Originalsystem und keine Berechtigungen auf Dateiebene. Wenn Ihre Agenten in den Antworten auf die Originaldatei verlinken sollen, synchronisieren Sie die Dokumente stattdessen über eine [Quelle](/de/company-gpt/addons/companyrag/quellen/) wie SharePoint.
:::

## Tabellen hochladen

Für tabellarische Daten, die per SQL abgefragt werden sollen, eignet sich eine [Datensatzsammlung](/de/company-gpt/addons/companyrag/datensaetze/). Laden Sie CSV-, Excel- oder Parquet-Dateien in eine Dokumentensammlung hoch, legt companyRAG sie als abfragbare Datensätze ab, sofern dort die Option [Tabellen als Datensätze](/de/company-gpt/addons/companyrag/sammlungen/#tabellen-als-datensätze) aktiviert ist.
