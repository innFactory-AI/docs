---
title: Bookmarks
description: Learn how to use bookmarks in CompanyGPT to quickly find conversations and group them by topic.
---

Bookmarks can be added to conversations to find them more quickly. This also allows chats on specific topics to be grouped together. A chat can carry several bookmarks.

## Adding a bookmark to a chat

Use the bookmark icon in the chat header (**Add Bookmarks**) to select an existing bookmark or create a new one with **New Bookmark**. In the dialog that opens, **Add to current conversation** is already selected, so the new bookmark is added to the open chat right away. Alternatively, use the keyboard shortcut `Ctrl` + `Shift` + `B` (macOS: `⌘` + `⇧` + `B`).

![bookmark](bookmark-en.png)

A bookmark has a **Title** and an optional **Description**.

## Filtering chats by bookmark

In the [chat history](/en/company-gpt/user-interface/#chat-history), open the **Filter and sort chats** icon next to the **Chats** heading. Under **Bookmarks**, select one or more bookmarks. Only bookmarks that are assigned to at least one chat appear there. The list then shows only chats that carry at least one of the selected bookmarks. The number of related chats is shown next to each bookmark.

Further filter and sort options are described in [Filtering and sorting](/en/company-gpt/user-interface/#filtering-and-sorting).

## Managing bookmarks

The **Bookmarks** entry in the sidebar shows all bookmarks with the number of related chats. There you can search bookmarks, create them with **New Bookmark**, edit, delete, and reorder them by drag and drop.
