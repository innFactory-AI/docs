## Rozhraní API

- [companyRAG API](/cs/api/company-rag-api/) – rozhraní API pro companyRAG Indexer
  - [Reference companyRAG API](/api/companyrag/) – úplná reference endpointů vygenerovaná ze specifikace OpenAPI
- [CompanyGPT Agents API](/cs/api/agents-api/) - API pro agenty CompanyGPT
- [AI Gateway API](/cs/api/ai-gateway/) – přístup k modelům AI Vašeho prostředí kompatibilní s OpenAI, Anthropic a Gemini pomocí osobního API klíče (není k dispozici ve všech prostředích)
