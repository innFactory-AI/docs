**Configuration** → **MCP domains** decides which domains MCP servers in CompanyGPT may use. You add your own domains here yourself, without innFactory.

## Base list and own domains

- **Base list (innFactory)** – comes from the CompanyGPT configuration and always applies. Entries CompanyGPT needs itself carry the badge **internal**. Only innFactory can change the base list.
- **Own domains** – are added to the base list and apply to everyone. Changes take effect without a restart within about a minute.

## Adding a domain

1. Enter one or more domains under **Add domain**, separated by spaces or commas.
2. Click **Add**.
3. Click **Save**. Before saving, the page shows what is added (**Added:**) and what is dropped (**Dropped:**).

| Possible | Not possible |
|---|---|
| `mcp.example.com` | `*` |
| `*.example.com` | A wildcard over a whole suffix such as `*.de` or `*.co.uk` |
| `https://mcp.example.com:8443` | Paths, parameters or credentials in the address |
| | Internal names and private IP addresses |
| | IPv6 addresses |
| | Services such as nip.io that point at any IP address |
| | Loopback, link-local and cloud metadata addresses |

The schemes http, https, ws and wss are allowed. If an entry is not allowed, companyADMIN saves nothing and gives the reason per entry.

## Removing a domain

Remove the domain from the list and save. **Remove domains?** asks first: after saving, MCP servers on these domains are blocked for everyone. Confirm with **Save and remove**.

## Special states

- **No domain list**: if your environment has no domain list, MCP servers may use any public domain; private addresses and internal names are blocked. Own domains would restrict that to the list and are therefore not possible.
- **List not from companyADMIN**: if the stored list was written elsewhere, saving replaces it with the base list, internal and own domains. companyADMIN asks first. You take over entries that do not come from companyADMIN with **Take over as own domains**.
- **Own list for roles or groups**: if a role or group has a domain list of its own, it applies to its members instead of the one maintained here. The page points this out.
- **Changed meanwhile**: if someone changed the list since you loaded it, companyADMIN saves nothing. Check the current state and save again.
