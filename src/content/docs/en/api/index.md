Welcome to the API Reference. Here you'll find documentation for all available APIs.

## APIs

- [companyRAG API](/en/api/company-rag-api/) – API interface for the companyRAG Indexer
  - [companyRAG API Reference](/api/companyrag/) – full endpoint reference, generated from the OpenAPI specification
- [CompanyGPT Agents API](/en/api/agents-api/) - API for CompanyGPT Agents
- [AI Gateway API](/en/api/ai-gateway/) – OpenAI-, Anthropic-, and Gemini-compatible access to the AI models of your environment with a personal API key (not available in all environments)
