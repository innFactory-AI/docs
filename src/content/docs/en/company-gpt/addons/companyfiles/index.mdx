---
title: Addon companyFILES
description: AI-powered document creation for CompanyGPT – create, convert and manage Excel, Word, PowerPoint and PDF files using natural language.
---

companyFILES lets you create, convert and manage documents directly in CompanyGPT. The addon combines file workflows, templates and visualizations in one central interface.

companyFILES has two entry points that work on the same set of files: the **chat**, where an agent calls the tools of the Files server and produces documents, and its **own interface**, which holds the same files and is where templates, visualizations and the defaults for generated documents are managed. Anything uploaded or produced in the chat can also be found in the interface – and vice versa.

## What you can create

| Format | Capabilities |
|---|---|
| Excel (`.xlsx`) | tables from CSV, JSON and arrays; advanced spreadsheets with formulas, conditional formatting and autofilters; filling templates |
| Word (`.docx`) | documents from Markdown, HTML or JSON; templates with placeholders; appending to or replacing content in existing documents |
| PowerPoint (`.pptx`) | presentations from text, templates or the layouts of a slide master; reading, extending and reworking individual slides of existing decks |
| PDF | PDFs from Markdown or HTML; reading and filling PDF forms |
| OpenDocument (`.odt`) | documents from text, HTML or templates |
| Text and code | any text-based file, for example SQL, JSON, YAML, XML, HTML, Python or JS |
| Visualizations | interactive charts, Mermaid diagrams and maps; exportable as images or embeddable in a document |

On top of that come reading and extracting data from existing files (Excel, Word, PDF), conversion between formats (e.g. Excel → CSV/JSON, Markdown/HTML/Word → PDF; see [File conversion](/en/company-gpt/addons/companyfiles/dokumente-erstellen/#file-conversion--data-extraction)) and ZIP archives for downloading several documents at once.

Depending on your environment, companyFILES can also:

- **read e-mails, archives and older formats** – Outlook messages including attachments, ZIP archives, `.doc`/`.xls`/`.ppt`, OpenDocument, EPUB and scans via text recognition; see [Reading e-mails, archives and older formats](/en/company-gpt/addons/companyfiles/dokumente-erstellen/#reading-e-mails-archives-and-older-formats).
- **analyze CAD, BIM and 3D models** – DXF, STEP, IFC, STL and further formats, with an interactive viewer in the chat; see [CAD, BIM and 3D](/en/company-gpt/addons/companyfiles/cad-und-3d/).

Newly created documents carry a machine-readable [AI label](/en/company-gpt/addons/companyfiles/dokumente-erstellen/#ai-labeling) in their metadata.

## Access

You reach the interface in CompanyGPT via **Apps → Files** or via the [All apps](/en/company-gpt/addons/alle-apps/) page. It uses the [shared interface](/en/company-gpt/addons/gemeinsame-oberflaeche/) of the CompanyGPT addons and signs you in with your chat session – no separate sign-in is needed.

In the chat, companyFILES is available as the **Files** tool; an agent with that tool and the matching skills is the usual starting point – see [Setting up the agent](/en/company-gpt/addons/companyfiles/agent/).
