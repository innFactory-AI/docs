---
title: Create Skill
description: Write, save, test and improve your own skills for companyGPT agents, following Anthropic's best practices for Agent Skills.
label: Create Skill
---

Use this skill when you want to turn a recurring task into a skill of your own. The agent interviews you (or takes
the workflow from the current chat), checks that a skill is the right tool and that every tool it names exists,
writes name, description and instructions, and tests the skill with realistic requests. If the agent may create
skills, it saves the skill directly; otherwise you get a `.zip` or the `SKILL.md` to upload under **Skills**.

:::note
Saving a skill directly needs an agent with skills enabled and a role that may create skills. Without that, the
agent hands you the finished skill to upload yourself.
:::
