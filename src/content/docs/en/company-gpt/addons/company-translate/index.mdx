companyTRANSLATE is a translation application that, like CompanyGPT, runs within the company's Microsoft tenant. It supports text and document translation as well as a two-level glossary system.

companyTRANSLATE is available to suitably authorised users in the **Translate** area.

## Access and Authentication

Access is exclusively via Microsoft Single Sign-On (SSO) using the existing company account. No separate credentials are required.

## Translation Services

The translation itself is performed via the Google Translation API and the Azure Translation API. The content to be translated is transmitted to the respective service for this purpose.

## Supported Formats and Limits

| Area | Input | Limit |
|---|---|---|
| **Translate text** | Direct entry in the interface | 5,000 characters per translation |
| **Translate document** | PDF, DOCX, PPTX | 40 MB per file |
| **Glossaries** | CSV, TSV (`.tsv`/`.tab`), XLIFF (`.xlf`), TMX | 10 MB per glossary; TMX is converted to XLIFF automatically |

## Translation History

All document translations are logged under **Letzte Übersetzungen** (recent translations) with target language, file size and timestamp.
