title: Upload
description: Upload single or multiple files manually to a collection and index them – with an overview of the supported file formats.
---

With **Upload** you add single or multiple files directly to a collection. This is the quickest way to test a set of documents or to add one-off documents. For recurring content, use a [source](/en/company-gpt/addons/companyrag/quellen/) instead.

Process on the **Upload Documents** page:

1. Select the **Collection** the documents should be added to. Only collections in which you are an owner or admin are offered. If there are none, the page shows **No writable collections**.
2. Drag files into the drop area or click to select them.
3. Start with **Upload Document** or **Upload … Documents**. The page shows the progress per file.
4. Each file is created as a job and indexed; you can see the status under [Jobs](/en/company-gpt/addons/companyrag/auftraege/).

## Supported formats

`.pdf`, `.txt`, `.md`, `.docx`, `.pptx`, `.xlsx`, `.rtf`, `.xml`, `.odt`, `.ods`, `.odp`, `.html`, `.htm`, `.csv`, `.tsv`, `.parquet`, `.json`, `.eml`

The legacy Excel format `.xls` is not supported. Save such files in Excel as a workbook (`.xlsx`).

The interface flags files larger than 50 MB with a notice. The maximum size of an upload is set by your environment.

:::note
Manually uploaded documents have no source link to an original system and no file-level permissions. If your agents should link to the original file in their answers, synchronize the documents via a [source](/en/company-gpt/addons/companyrag/quellen/) such as SharePoint instead.
:::

## Uploading tables

For tabular data that should be queried via SQL, a [dataset collection](/en/company-gpt/addons/companyrag/datensaetze/) is the right choice. If you upload CSV, Excel or Parquet files to a document collection, companyRAG stores them as queryable datasets as long as the option [Tabular files as datasets](/en/company-gpt/addons/companyrag/sammlungen/#tabular-files-as-datasets) is enabled there.
